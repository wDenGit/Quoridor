# Quoridor Game (C++ / Qt)

## 📌 Description

This project is an implementation of the board game **Quoridor** developed in C++ using the Qt framework.

The goal of the game is to move a pawn from one side of the board to the opposite side while strategically placing walls to block the opponent. The project focuses on game logic, graphical user interface design, and structured software development.

---

## 🎮 Features

* Full implementation of Quoridor game rules
* Graphical user interface using Qt
* Player movement with rule validation
* Wall placement system
* Turn-based gameplay
* Win condition detection
* Interactive board visualization
* Game state management

---

## 🛠️ Technologies

* C++
* Qt framework (GUI development)
* Object-Oriented Programming (OOP)
* Event-driven programming
* Basic algorithms (path validation and game logic)
